# 中文个人作品集三页改造设计

设计日期：2026-08-24

## 目标

将现有 Deslopify 静态镜像改造成中文个人作品集，并在保持当前高完成度视觉语言、响应式规则和主要动效的前提下，形成首页、作品集、AI 学习三个独立页面。

## 已确认范围

- 全站用户可见文案改为自然、简洁的中文。
- 导航栏 Logo 改为代码原生的小树 SVG；不引入位图 Logo。
- 新增独立作品集页 `works.html`。
- 新增独立 AI 学习文章列表页 `ai-learning.html`。
- 首页保留现有作品展示区。
- 作品集页展示现有全部项目素材，并提供比首页更完整的浏览方式。
- 首页删除完整价格表区域。
- 首页删除客户评价区域。
- 删除联系入口，包括导航 CTA、预约入口和 Cal.com 嵌入。
- 保留首页其余核心区块：首屏、改造前后对比、流程、设计细节、个人介绍、作品展示和固定揭示式页脚。

## 信息架构

### 共享导航

三页使用同一导航结构：

1. 小树 Logo，点击返回 `index.html`。
2. 首页，指向 `index.html`。
3. 作品集，指向 `works.html`。
4. AI 学习，指向 `ai-learning.html`。
5. 关于，在首页指向 `#about`；其他页面指向 `index.html#about`。

不保留“联系我”“预约通话”或价格入口。当前页面导航项使用 `aria-current="page"` 和清晰选中态。

### 首页 `index.html`

按以下顺序组织：

1. 中文首屏与改造前后手机跑马灯。
2. 改造前后对比 sticky 区域。
3. 首页作品展示区，保留 App 设计 / App Store 展示图切换和项目图标选择。
4. 三阶段工作流程 sticky 区域。
5. 设计细节 Bento 区域。
6. 个人介绍区域。
7. 固定揭示式小树主题页脚。

移除价格区域、客户评价区域、Cal.com 预约区域及所有指向这些区域的链接。移除区块后重新计算长页节奏，避免留下空白跑道。

### 作品集页 `works.html`

页面沿用首页的白底、深蓝标题、蓝紫强调色和圆角设备展示语言。

结构：

1. 页面标题与简短中文说明。
2. “App 设计 / App Store 展示图”分类切换。
3. Founder、Indus、Hush、Flyout、Justgains 五个项目分组。
4. 每组显示项目名称、项目类型、简短说明和全部现有项目图片。
5. 页脚返回首页与 AI 学习页，不提供联系 CTA。

项目素材全部复用本地 `assets/projects/`、`assets/screens/` 和现有图标，不引入占位图或远程图片。

### AI 学习页 `ai-learning.html`

这是一个中文文章列表页，不实现文章正文路由或 CMS。

结构：

1. 页面标题、学习理念和简短说明。
2. 一篇精选文章卡。
3. 六篇文章列表，主题覆盖：AI 学习方法、提示词、Agent、自动化、AI 编程、工具选择。
4. 每篇显示分类、标题、摘要、阅读时长与静态状态标签。
5. 卡片当前不跳转到不存在的正文；使用语义化 `<article>`，不伪造可点击链接。

首版文章文案应像个人学习笔记，不使用夸张营销语或虚构成绩。

## 视觉与品牌

- 保留 Inter 与 Plus Jakarta Sans 字体组合；中文使用系统中文无衬线回退，避免额外字体下载。
- 保留当前主色：深蓝、蓝紫、白色和淡灰紫。
- 小树 Logo 使用 24×24 内联 SVG，由树冠、树干和两片叶子组成，笔画简洁，支持 `currentColor`。
- 首页继续使用现有项目图片、Canvas 弹珠罐和页脚天气效果；页脚中的品牌文字改为中文个人作品集语境。
- 新页面不复制首页长距离 sticky 动画，重点放在内容扫描效率和图片质量。
- 不引入新的设计系统、框架、构建步骤或外部 UI 库。

## 中文文案原则

- 优先表达用户能看到什么和获得什么，避免逐字翻译英文。
- 标题短，正文句子尽量控制在 24 个汉字左右。
- 按钮与导航使用动词或明确名词，如“查看作品集”“AI 学习”。
- 删除与价格、销售、预约通话和客户背书相关的文案。
- 不虚构客户、评价、数据、文章发布日期或个人履历。

## 技术实现

- 保持原生 HTML/CSS/JavaScript。
- `index.html` 继续加载 `styles.css` 和 `script.js`。
- `works.html`、`ai-learning.html` 共享 `styles.css`，并加载一个小型共享页面脚本 `pages.js`；不加载首页专用长页动效脚本。
- 首页脚本必须容忍价格、评价和预约 DOM 被删除；任何查询都应在节点不存在时安全返回。
- 新页面使用独立根类 `.works-page`、`.learning-page`，避免覆盖首页已有样式。
- 所有内部链接使用相对路径，保证 `file://` 和本地 HTTP 服务均可访问。

## 边界与错误处理

- 若项目图片加载失败，保持卡片尺寸并隐藏破损图标，不回退到远程 URL。
- 若 JavaScript 不可用，作品集项目与 AI 文章仍完整可读；分类切换退化为连续内容。
- `prefers-reduced-motion` 下停止自动跑马灯和装饰动画。
- 移动端不得横向溢出，导航项保持可点击，项目图片按单列或双列自然重排。

## 验收标准

1. 三个页面均可通过 `file://` 和本地 HTTP 打开。
2. 所有用户可见英文品牌、标题、导航、按钮和正文均完成中文化；素材内嵌英文截图不强制改图。
3. 首页作品展示仍可切换分类与项目。
4. 首页不存在价格表、客户评价、联系 CTA 或 Cal.com iframe。
5. 作品集页完整引用 Founder、Indus、Hush、Flyout、Justgains 的本地项目素材。
6. AI 学习页显示精选文章与六篇文章列表，不出现死链。
7. 三页导航、树 Logo 和当前页状态一致。
8. 1440×900、768×900、390×844 下无横向溢出、遮挡或异常空白。
9. 控制台没有由已删除 DOM 导致的新异常。
10. 原站既有的可见互动在保留区域内继续工作。

## 不在本轮范围

- 不实现文章详情页、Markdown 渲染、搜索、CMS 或后台。
- 不替换项目截图中的英文内容。
- 不添加价格、客户评价、联系表单或预约服务。
- 不部署网站，不改造成 React/Tailwind。
